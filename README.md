# 🌱 Green IT: Análise de Impacto Ambiental em Data Centers

Projeto de análise de dados focado em investigar a pegada ecológica, emissões de CO₂ e a sustentabilidade associada à infraestrutura de tecnologia e grandes centros de dados.

## 🎯 Objetivo Geral
Analisar métricas de emissões e impacto ambiental utilizando dados públicos, aplicando ferramentas de ciência de dados para gerar insights sobre eficiência energética e práticas sustentáveis em TI.

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagem:** Python
- **Ambiente de Desenvolvimento:** Google Colab / Visual Studio Code (VS Code)
- **Análise e Tratamento de Dados:** Pandas, NumPy
- **Visualização de Dados:** Matplotlib, Seaborn

## 📂 Etapas do Projeto
1. **Coleta e Limpeza de Dados:** Importação de datasets (ex: Kaggle) e tratamento de valores ausentes.
2. **Análise Exploratória:** Investigação de padrões de emissão de CO₂ por região/setor.
3. **Visualização de Resultados:** Construção de gráficos comparativos para apoiar estratégias de TI verde.
